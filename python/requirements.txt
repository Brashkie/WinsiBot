# ── Lo que se fue en la 8.11.0 ───────────────────────────────────────────────
#
# Acá estaban los tres comandos de imagen, que eran lo último que de verdad
# ataba el proyecto a Python. Al mirarlos de cerca resultó que **dos de los tres
# ni siquiera usaban torch**: `dghs-imgutils` ya corría sus modelos con ONNX
# Runtime, y torch era apenas un `extra` suyo que este proyecto no usaba.
#
# Los tres están ahora en rust/src/vision.rs:
#
#   #toanime   AnimeGANv2 en ONNX, 8 MB de modelo   (antes: torch, 3,7 GB)
#   #removebg  isnetis en ONNX, 168 MB de modelo    (antes: onnxruntime + imgutils + cv2)
#   #upscale   Anime4K portado — no es una red sino un algoritmo, sin modelo
#
# Se fueron con ellos: torch, pillow, pyanime4k, dghs-imgutils, onnxruntime y
# opencv-contrib-python. Más de 4 GB de dependencias por tres comandos.
#
# Y lo que más importa para instalar: en Termux el problema nunca fue que
# faltaran binarios —las ruedas de PyPI YA son binarios (.so dentro del .whl)—
# sino la libc. Las ruedas de ARM se publican como `manylinux`, que asume glibc,
# y Android usa Bionic. ONNX Runtime enlazado dentro del binario de Rust no
# tiene ese problema: los tres comandos funcionan en cualquier plataforma donde
# compile Rust.
